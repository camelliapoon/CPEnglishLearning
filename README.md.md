# 📚 Camellia English Classroom - 現代英文教學部落格 & 官網

一個專為英文教學設計的響應式（Responsive）靜態網站，具備現代極簡風格與流暢的互動體驗。專案採用 HTML5、Tailwind CSS 與 Vanilla JavaScript 開發，並完全相容於 **GitHub Pages** 免費託管服務。

---

## 🌟 專案亮點 (Features)

- **現代極簡視覺 (Modern Minimalist Design)：** 以深藍與天藍為主色調，注重留白與文字易讀性。
- **完全響應式佈局 (Fully Responsive)：** 支援 Desktop、Tablet 與 Mobile 裝置，含手機端滑出式導覽選單。
- **模組化檔案結構 (Clean Code Structure)：** HTML、CSS 與 JS 檔案分離，方便擴充與維護。

---
